PROJETO CORDEL MODERNO

SEGUE AQUI O LINK PARA A PÁGINA: https://brunomarion.github.io/projeto-cordel/




Nesse projeto desenvolvido com HTML5, CSS3 e Javascript foi um desafio de um curso de Desenvolvimento Web. 
Uma página web sobre um cordel de Milton Duarte, usando o efeito paralax nas imagens e acrescentando algumas animações com o uso o Intersection Observer do Javascript.


O projeto Cordel Moderno tem como objetivo apresentar e celebrar os cordéis do renomado poeta Milton Duarte. Milton Duarte é um talentoso escritor e cordelista, conhecido por suas narrativas únicas e cativantes, que mesclam tradição e modernidade.

Durante o desenvolvimento deste projeto, tentei garantir que a essência e o estilo dos cordéis de Milton Duarte fossem refletidos no design e na apresentação do site. Foi necessário aplicar habilidades em HTML, CSS e JavaScript para criar um ambiente visual atraente, que complementasse a experiência de leitura dos cordéis. Nesse projeto procurei desenvolver mais meu entendimento e olhar sobre a página visando sempre melhorar a experiência do usuário.

Se você também é um entusiasta da poesia popular ou está interessado em descobrir a arte dos cordéis de Milton Duarte, visite o site aqui: https://www.recantodasletras.com.br/autor_textos.php?id=9806&categoria=7 e mergulhe nesse mundo fascinante de histórias rimadas.
